Akun & Login
Kunjungi ngebut-in.vercel.app lalu klik "Daftar". Isi Nama Lengkap, Email, dan Password. Akun langsung aktif setelah pendaftaran berhasil — tidak perlu verifikasi email. Atau, buka aplikasi Android dan pilih "Daftar".
Klik "Lupa Password?" di halaman login → Masukkan email terdaftar → Ikuti instruksi reset password yang dikirim ke email Anda. Jika tidak menerima email, periksa folder Spam/Junk atau hubungi CS kami via WhatsApp.
Di aplikasi: Buka menu Profil → Edit Profil. Di website: Masuk dashboard → klik ikon profil. Anda bisa mengubah Nama, Email, foto profil (dari kamera atau galeri), dan password. Foto ditampilkan proporsional tanpa terpotong.
Booking Motor
  1. Login ke akun Anda
  2. Pilih motor dari katalog yang berstatus Tersedia
  3. Klik "Sewa Sekarang"
  4. Tentukan Tanggal Mulai dan Tanggal Selesai
  5. Periksa total harga dan DP (50%)
  6. Klik "Pesan Sekarang"
💡 Setelah booking, segera upload bukti DP agar motor dikonfirmasi.
Pembatalan hanya bisa dilakukan sebelum DP diverifikasi admin. Setelah DP diverifikasi dan motor aktif disewa, hubungi Customer Service kami untuk penanganan lebih lanjut terkait kebijakan pengembalian dana.
Saat pengambilan motor, siapkan: KTP asli dan SIM C yang masih aktif. Tidak perlu mengupload dokumen ini ke aplikasi — cukup tunjukkan saat serah terima unit.
Pembayaran & DP
Pembayaran dibagi 2 tahap:

1. DP (50% di muka) — Transfer 50% dari total harga ke rekening Ngebut.in, lalu upload screenshot bukti transfer di aplikasi/website.

2. Pelunasan (50% saat kembali) — Bayar sisa 50% ketika mengembalikan motor. Upload bukti pelunasan di aplikasi, admin akan mengkonfirmasi dan transaksi selesai.
Di aplikasi: Booking Saya → pilih booking Pending → Upload Bukti DP → ambil foto atau pilih dari galeri → Submit.
Di website: Dashboard → Booking → tombol Upload DP.

Pastikan foto bukti transfer jelas terbaca (nominal, tanggal, rekening tujuan).
Admin kami memverifikasi bukti DP dalam 15–30 menit selama jam operasional (07.00–21.00 WIB). Anda akan menerima email notifikasi otomatis saat DP disetujui dan motor aktif disewa.
Kwitansi
Kwitansi tersedia setelah sewa selesai (status: Selesai). Cara akses: Booking Saya → pilih booking Selesai → Lihat Kwitansi. Browser akan membuka halaman kwitansi resmi dengan logo Ngebut.in yang bisa dicetak atau disimpan sebagai PDF (Ctrl+P → Save as PDF).
Aplikasi Mobile
  1. Buka ngebut-in.vercel.app di browser HP
  2. Klik tombol "Download APK" (18.3 MB)
  3. Tunggu download selesai
  4. Buka file APK yang terunduh
  5. Jika muncul peringatan, aktifkan "Instal dari sumber tidak dikenal" di Pengaturan → Keamanan
  6. Klik Install → selesai
