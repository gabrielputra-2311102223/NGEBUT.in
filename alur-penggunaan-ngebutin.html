📋 Gambaran Umum Sistem

Ngebut.in adalah platform rental motor berbasis digital yang menyediakan aplikasi mobile (Android) dan website. Sistem ini memiliki 4 peran pengguna dengan fitur dan alur yang berbeda.

📱 Aplikasi Mobile

  • Download APK dari website (18.3 MB)
  • Tersedia untuk Android
  • Login: User, Admin, Owner
  • Fitur booking, upload DP, kwitansi

🌐 Website

  • URL: ngebut-in.vercel.app
  • Landing page & katalog motor
  • Dashboard User & Admin berbasis web
  • Booking & manajemen lengkap
Peran Platform Akses Utama
👤 User App & Website Booking motor, upload DP, lihat status sewa, cetak kwitansi
🛡️ Admin App & Website Verifikasi DP, kelola kendaraan, manajemen user, konfirmasi pelunasan
👑 Owner App & Website Dashboard laporan, statistik, export Excel
🔄 Alur Status Booking
⏳ Pending → User upload DP → 🕐 DP Uploaded → Admin verifikasi → ✅ Confirmed (Aktif) → Motor dikembalikan → 🔄 Returning → Pelunasan dikonfirmasi → 🏁 Selesai
ℹ️
Sistem DP: Pembayaran dibagi 2 tahap — DP 50% di awal booking (diupload buktinya) dan Pelunasan 50% saat motor dikembalikan. Admin memverifikasi kedua pembayaran tersebut.

Alur Pengguna (User)

Penyewa motor — menggunakan Aplikasi Mobile atau Website

📝 1. Registrasi & Login
1
🌐 Buka Website atau 📱 Download Aplikasi
Kunjungi ngebut-in.vercel.app atau download APK dari tombol "Download APK" di halaman utama website (18.3 MB, gratis).
Website Android APK
2
✍️ Daftar Akun Baru
Klik "Daftar" → Isi Nama Lengkap, Email, Password. Akun langsung aktif setelah registrasi berhasil.
Nama Lengkap Email Password Role: User (otomatis)
3
🔑 Login ke Akun
Masukkan Email dan Password yang terdaftar. Jika salah akan muncul pesan "Email atau password salah" (tanpa detail teknis).
App & Website
🏍️ 2. Browsing & Booking Motor
4
📋 Lihat Katalog Motor
Browse daftar motor yang tersedia. Filter berdasarkan kategori: Matic, Manual, Sport. Lihat harga per hari, gambar, deskripsi, dan status ketersediaan.
Matic Manual Sport Status: Tersedia / Disewa
5
📅 Isi Form Booking
Pilih motor yang diinginkan → Tentukan Tanggal Mulai dan Tanggal Selesai sewa. Sistem otomatis menghitung total harga dan besaran DP (50%).
Total Harga = Durasi × Harga/hari DP = 50% dari Total
6
✅ Konfirmasi Booking
Klik "Pesan Sekarang". Booking tersimpan dengan status Pending dan menunggu pembayaran DP.
💳 3. Pembayaran DP (50%)
7
💸 Transfer DP ke Rekening Ngebut.in
Lakukan transfer sejumlah DP (50% dari total harga) ke rekening yang tertera. Simpan bukti transfer/screenshot sebagai bukti pembayaran.
8
📸 Upload Bukti DP di Aplikasi/Website
Buka menu "Booking Saya" → Pilih booking yang berstatus Pending → Klik "Upload Bukti DP" → Ambil foto atau pilih dari galeri → Submit.
App: Booking Saya → Upload DP Website: Dashboard → Booking
9
⏳ Tunggu Verifikasi Admin
Status berubah menjadi DP Uploaded. Admin akan memverifikasi bukti DP dalam 15–30 menit. Anda akan mendapat notifikasi email saat motor dikonfirmasi aktif.
📧 Email Konfirmasi Otomatis
🏍️ 4. Masa Sewa Aktif
10
✅ Motor Aktif Disewa
Setelah DP diverifikasi, status berubah menjadi Aktif Sewa. Motor siap digunakan sesuai tanggal yang dipilih.
11
🔔 Pengingat Email Otomatis
Sistem mengirim notifikasi email pengingat secara otomatis 1 hari sebelum masa sewa berakhir agar pengembalian tepat waktu.
📧 Email H-1 sebelum tanggal kembali
🔄 5. Pengembalian & Pelunasan
12
🏍️ Kembalikan Motor
Kembalikan motor ke lokasi Ngebut.in sesuai tanggal. Admin akan menandai motor sebagai Proses Kembali.
13
💰 Bayar Pelunasan (50%)
Lakukan pembayaran sisa 50% dari total harga. Upload bukti pelunasan lewat aplikasi/website seperti saat upload DP.
14
🏁 Sewa Selesai
Setelah admin mengkonfirmasi pelunasan, status berubah menjadi Selesai. Kwitansi digital tersedia untuk diunduh.
🧾 6. Kwitansi Digital
15
📄 Lihat & Cetak Kwitansi
Buka "Booking Saya" → Pilih booking berstatus Selesai → Klik "LIHAT KWITANSI". Browser akan membuka halaman kwitansi resmi dengan logo Ngebut.in yang bisa dicetak atau disimpan sebagai PDF.
Berisi: Nama, Motor, Tanggal, Total, DP, Pelunasan Bisa Cetak / Simpan PDF
👤 7. Edit Profil
16
✏️ Ubah Data Profil
Menu Profil → Edit data (Nama, Email, Foto Profil dari Kamera/Galeri) atau ganti password. Foto profil tampil proporsional tanpa terpotong.
NamaEmailFoto ProfilGanti Password

Alur Administrator

Pengelola operasional — menggunakan Aplikasi Mobile atau Website

🔑 1. Login Admin
1
🔐 Login dengan Akun Admin
Gunakan email dan password akun admin yang diberikan oleh Owner. Sistem otomatis mengarahkan ke Dashboard Admin setelah login berhasil.
Role: Admin App & Website
📊 2. Dashboard Admin
2
📈 Lihat Statistik Real-time
Dashboard menampilkan ringkasan: Total Kendaraan, Tersedia, Disewa, Menunggu DP, Verifikasi DP, Dikembalikan, dan Selesai.
Total Kendaraan Tersedia Disewa Menunggu DP Verifikasi DP
3
📋 Daftar Booking Terkini
Dashboard menampilkan booking terbaru dengan badge status berwarna. Klik item untuk melihat detail atau langsung aksi verifikasi.
✅ 3. Verifikasi DP
4
🗂️ Buka Menu Verifikasi DP
Dari menu navigasi (drawer/sidebar) pilih "Verifikasi DP". Tampil daftar semua booking yang sudah upload bukti DP dan menunggu verifikasi.
Status: DP Uploaded
5
🔍 Periksa Bukti DP
Klik booking untuk melihat detail: Nama penyewa, motor, tanggal sewa, jumlah DP, dan foto bukti transfer yang diupload user.
6
✅ Setujui atau ❌ Tolak DP
Approve: DP valid → Klik "Setujui" → Status booking berubah ke Confirmed → Motor otomatis berubah status Disewa.

Tolak: DP tidak valid → Klik "Tolak" → Masukkan alasan penolakan → User diberi tahu.
Setujui → Motor Aktif Tolak → Kembali Pending
💳 4. Manajemen Pembayaran
7
🗂️ Buka Menu Pembayaran
Menu "Pembayaran" memiliki 3 tab:
• Aktif Sewa: Booking yang DP-nya sudah diverifikasi (status Confirmed)
• Proses Kembali: Motor sudah dikembalikan, menunggu konfirmasi pelunasan
• Selesai: Transaksi tuntas
8
🔄 Tandai Motor Dikembalikan
Tab Aktif Sewa → Temukan booking → Klik "TANDAI KEMBALI" saat user menyerahkan motor. Status berubah ke Proses Kembali.
9
✅ Konfirmasi Pelunasan & Selesaikan
Tab Proses Kembali → Verifikasi bukti pelunasan → Klik "KONFIRMASI PELUNASAN & SELESAI". Status berubah ke Selesai dan kwitansi tersedia.
10
🧾 Lihat Kwitansi
Pada booking berstatus Selesai, klik "LIHAT KWITANSI" untuk membuka kwitansi resmi di browser. Admin juga bisa melihat dan mencetak kwitansi transaksi.
Tersedia untuk Admin & User
🏍️ 5. Kelola Kendaraan
11
➕ Tambah Motor Baru
Menu "Kelola Kendaraan" → Klik Tambah → Isi nama, kategori (Matic/Manual/Sport), harga/hari, deskripsi, dan upload foto motor.
12
✏️ Edit / Hapus Motor
Pilih motor dari daftar → Edit data (nama, harga, gambar, kategori) atau hapus motor yang sudah tidak aktif.
Kategori: Matic / Manual / Sport
👥 6. Manajemen Pengguna
13
👁️ Lihat Daftar Pengguna
Menu "Manajemen User" → Tampil semua akun yang terdaftar beserta nama, email, role, dan jumlah booking.
